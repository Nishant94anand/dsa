## Index conventions

- **Sequence** is prerequisite-oriented; Phase 12 is a parallel practice and revision programme that should begin immediately, not after Phase 11.
- **Depth** defines expected learning depth, not current learner rating or progress status. Existing Java work does not automatically mark a chapter complete.
- **Notes / Practice** intentionally show `—` until real artifacts exist. New chapter Markdown and practice code will be linked after actual work and approval.
- **Planned** means the curriculum has defined the chapter; authoritative learning status will be tracked in `PROGRESS.md` when that file is created. Do not infer historical progress.

## Artifact-link policy
