## How to use this index

- **Phase order:** Phases 0–6 build core interview skill; Phase 7 adds Principal/Architect coding judgment. Individual phase prerequisites are in the syllabus.
- **Practice starts immediately:** do problems, timed sets and revision *throughout* the phases; these are not postponed to the end.
- **Notes (`—`):** no chapter note is linked yet; once the learner approves chapter completion, link the actual GitHub note under `Notes/`.
- **Code (`—`):** no practice implementation is linked yet in this index; link real newly committed files under `PracticeCodes/` or verified relevant legacy/LeetCode solutions after review.
- **Progress and ratings:** managed separately when progress/revision files are created; neither previous solved code nor this index implies a completed lesson.
